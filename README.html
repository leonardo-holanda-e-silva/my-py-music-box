My Py Music Box

Basic instructions to run the app on Windows, macOS, and Linux.

What you need

  • Speakers or headphones connected
  • Python 3.11 or newer, if you are running from source
  • The uv tool, if you are running from source

If you received an installer (.msi, .exe, .dmg, .AppImage, or .deb), use the section for your operating system. If you only have the project folder, use “From source”.

Windows

The installer for this version is dist/My Py Music Box-0.1.0.msi.

  1. Open the .msi and follow the wizard. If Windows SmartScreen warns that the publisher is unknown, choose More info and then Run anyway.
  2. Start My Py Music Box from the Start menu or the desktop shortcut.

Without an installer (from source), in PowerShell, in the project folder:

uv sync
uv run my-py-music-box

macOS

With an installer:

  1. Open the .dmg file.
  2. Drag My Py Music Box into Applications.
  3. Open the app. If the system warns that it is unsigned, use Open Anyway in Settings → Privacy & Security.

Without an installer (from source), in Terminal, in the project folder:

uv sync
uv run my-py-music-box

Linux

With a package:

  • AppImage: make it executable (chmod +x on the file) and double-click it, or run it from a terminal.
  • Deb: install it with your distribution’s package manager, then open My Py Music Box from the applications menu.

Without a package (from source), in a terminal, in the project folder:

uv sync
uv run my-py-music-box

If audio fails to open, install the system PortAudio library (for example libportaudio2 on Debian/Ubuntu).

From source (any system)

  1. Install Python 3.11+ and uv.
  2. Open a terminal in the project folder.
  3. Run:
uv sync
uv run my-py-music-box

The app window should open with the Play, Composer, and Settings pages.

First use

  1. On the Play page, open the sample file examples/example.caixa.json.
  2. Press Play and check that sound comes through your speakers or headphones.
  3. Use Composer to edit the cylinder and Settings for volume and audio device.

Score files use the .caixa.json extension.
