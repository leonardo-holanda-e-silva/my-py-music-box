My Py Music Box

Kivy Android POC. Scores in SQLite; JSON import/export.

Android APK

On WSL/Linux, in the project folder:

pip install buildozer
buildozer android debug

Install bin/*.apk on the phone. Built-in scores: Example and How Deep Is Your Love.

Desktop smoke test

uv sync
uv run my-py-music-box

Tests

uv run pytest
