My Py Music Box

Instruções básicas para executar o aplicativo no Windows, macOS e Linux.

O que você precisa

  • Alto-falantes ou fones de ouvido ligados
  • Python 3.11 ou mais novo, se for executar a partir do código-fonte
  • O gerenciador uv, se for executar a partir do código-fonte

Se você recebeu um instalador (.msi, .exe, .dmg, .AppImage ou .deb), use a seção do seu sistema operacional. Caso tenha apenas a pasta do projeto, use a seção “A partir do código-fonte”.

Windows

O instalador desta versão é o arquivo dist/My Py Music Box-0.1.0.msi.

  1. Abra o .msi e siga o assistente. Se o Windows SmartScreen avisar que o editor é desconhecido, use Mais informações e depois Executar mesmo assim.
  2. Inicie My Py Music Box pelo menu Iniciar ou pelo atalho da área de trabalho.

Sem instalador (código-fonte), no PowerShell, na pasta do projeto:

uv sync
uv run my-py-music-box

macOS

Com instalador:

  1. Abra o arquivo .dmg.
  2. Arraste My Py Music Box para a pasta Aplicativos.
  3. Abra o aplicativo. Se o sistema avisar que o app não foi assinado, use Abrir mesmo assim em Ajustes → Privacidade e segurança.

Sem instalador (código-fonte), no Terminal, na pasta do projeto:

uv sync
uv run my-py-music-box

Linux

Com pacote:

  • AppImage: dê permissão de execução (chmod +x no arquivo) e dê dois cliques, ou execute-o no terminal.
  • Deb: instale com o gerenciador de pacotes da sua distribuição e abra My Py Music Box no menu de aplicativos.

Sem pacote (código-fonte), no terminal, na pasta do projeto:

uv sync
uv run my-py-music-box

Se o áudio não abrir, instale a biblioteca PortAudio do sistema (por exemplo libportaudio2 no Debian/Ubuntu).

A partir do código-fonte (qualquer sistema)

  1. Instale o Python 3.11+ e o uv.
  2. Abra um terminal na pasta do projeto.
  3. Execute:
uv sync
uv run my-py-music-box

A janela do aplicativo deve abrir com as páginas Play, Composer e Settings.

Primeiro uso

  1. Na página Play, o app tenta abrir examples/How Deep Is Your Music Box.caixa.json. Se precisar, use Example ou Open.
  2. Aperte Play e confira se o som sai nos alto-falantes ou fones.
  3. Use Composer para editar o cilindro e Settings para volume e dispositivo de áudio.

Arquivos de partitura usam a extensão .caixa.json.
