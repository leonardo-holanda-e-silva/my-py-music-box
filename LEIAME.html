My Py Music Box

POC Kivy para Android. Partituras em SQLite; import/export JSON.

APK Android

No WSL/Linux, na pasta do projeto:

pip install buildozer
buildozer android debug

Instale o arquivo em bin/*.apk no celular. Já vêm as partituras Example e How Deep Is Your Love.

Teste no desktop

uv sync
uv run my-py-music-box

Testes

uv run pytest

My Py Music Box is open-source software.
